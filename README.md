# StainNormalization

Research project investigating whether stain normalization changes the
performance ranking between capsule-based and convolutional models
in stained microscopy image classification.

## Project Structure

- src/normalization: Reinhard and Macenko normalization methods
- src/models: Capsule networks and CNN baseline
- src/utils: Helper functions
- notebooks: Experiment notebooks
- configs: Experiment configurations
- data: Datasets (not tracked by Git)
